# Открытка «С Днём учителя!»

Мобильный сайт-открытка на React + JavaScript (Vite).

Как устроена: конверт с сургучной «5» → доска, на которой мелом пишется поздравление (RU + KZ) → кнопка «Поставить пятёрку» рисует мелом оценку, с листопадом, вибрацией и колокольчиком. Листья падают на canvas и сдвигаются, когда наклоняешь телефон (на Android). На компьютере вместо открытки показывается QR-код и кнопка «Посмотреть здесь».

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173 (с --host откроется и с телефона в той же Wi‑Fi)
npm run build    # готовый сайт в папке dist/
```

## Публикация

Папка `dist/` — обычная статика, `base: './'`, поэтому подходит любой хостинг:

- **Vercel / Netlify**: импортируйте репозиторий, команда сборки `npm run build`, папка `dist`.
- **GitHub Pages**: загрузите содержимое `dist/` в ветку `gh-pages`.

Чтобы превью в Telegram/WhatsApp показывало картинку, после публикации замените в `index.html`
`content="og.jpg"` на полный адрес, например `https://ваш-сайт.vercel.app/og.jpg`.

## Личная открытка

Кому, от кого и текст задаются в ссылке:

```
https://ваш-сайт/?to=Дорогая Айгерим Сериковна&from=Ученики 11 «А»&msg=Свой текст
```

Удобнее собрать ссылку кнопкой «Сделать свою» в конце открытки. Тексты по умолчанию — в `src/config.js`.

## Структура

```
src/
  config.js              тексты, параметры ссылки
  App.jsx                телефон / компьютер (QR)
  components/
    Card.jsx             рама, сцены, звук, «поделиться»
    EnvelopeScene.jsx    конверт с анимацией открытия
    Board.jsx            доска: расписание «письма мелом», оценка
    ChalkText.jsx        побуквенное появление текста
    Grade.jsx            пятёрка мелом (SVG-обводка)
    Leaves.jsx           листопад на canvas + «взрыв» листьев
    CreateSheet.jsx      форма «Своя открытка»
    DesktopGate.jsx      экран с QR-кодом для компьютера
  lib/sound.js           колокольчик и шорох бумаги (WebAudio, без файлов)
```
